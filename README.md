<h1>Super Ultra Hacker</h1>
A keyboard testing toy written in go using tview. Hit keys on your keyboard to write code. Watch your victims react, and your friends talk about their hacks.

Written in go over a couple weeks for fun. Feature complete, but could use more dialogue.

<h2>
Building  
</h2>
Clone the repo, cd in, and use `go build -o hacker && ./hacker' to run.
